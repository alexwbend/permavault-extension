# Store artwork

Use the four PNGs in `screenshots/` in filename order. They are 1280×800 RGB images. `small-promo.png` is the required 440×280 RGB promotional tile. `icon.png` matches the production package icon.

The first two visuals frame the actual compiled v0.2.4 signed-out popup. Its rendering used inert local browser functions and empty account storage only to display the real component; no recording, payment or upload result was simulated. The remaining two visuals explain actual storage choices and pricing; they are illustrations, not fabricated software screens.

Artwork uses the canonical Permavault vectors and Vault/Paper palette with IBM Plex fonts. Editable layouts and the source component capture are retained in the main project's private `internal/marketing/2026-10-13-store-refresh/` folder. Regenerate the product view whenever popup layout or content changes.

These images do not replace installed-release acceptance tests. Submission, approval and public availability must be verified separately in the publisher console.
